# Firouzeh Hair & Beauty — Salon Kasse v0.5.0-test

وب‌اپ دوزبانه فارسی و آلمانی برای مدیریت صندوق نقدی
`Firouzeh_hair_beauty`.

## امکانات نسخه

- رابط فارسی RTL و آلمانی LTR
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- ثبت فروش خدمات و پکیج‌ها
- ثبت انعام و محاسبه باقی‌مانده
- ورود و خروج نقدی و بستن روز
- مدیریت، ویرایش، فعال/غیرفعال‌کردن و حذف خدمات و پکیج‌ها
- نگهداری قیمت فروش‌های قبلی پس از حذف خدمت
- خروجی Excel چندبرگی و بکاپ JSON
- IndexedDB و PWA
- Splash Screen و انیمیشن‌های سبک
- Docker، Caddy و GitHub Actions

> نسخه تست هنوز نباید به‌عنوان صندوق رسمی مالیاتی آلمان استفاده شود.

## اجرای Windows

Node.js 24 LTS باید نصب باشد.

```text
scripts/START_FIROUZEH_KASSE.bat
```

یا:

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

## اطلاعات محلی

داده‌ها داخل IndexedDB مرورگر ذخیره می‌شوند. حذف یک خدمت از فهرست
قیمت، تراکنش‌ها و گزارش‌های قبلی را حذف نمی‌کند.
