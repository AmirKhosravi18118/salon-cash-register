1) فایل ZIP را دانلود و Extract کنید.
2) پوشه Firouzeh_Kasse_Update_v0.5.0 را مستقیماً داخل مسیر زیر قرار دهید:

D:\salon-cash-register

3) فایل زیر را اجرا کنید:

اسکریپت به‌صورت خودکار:

- سورس جدید را جایگزین می‌کند.

- Build نسخه Production را اجرا می‌کند.
- اگر Build شکست بخورد، فایل‌های نسخه قبل را برمی‌گرداند.
- اگر همه‌چیز موفق باشد، برنامه را باز می‌کند.
