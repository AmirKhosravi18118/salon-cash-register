Firouzeh Hair & Beauty — Update v0.6.0-test
================================================

نصب
----
1) پنجره اجرای نسخه قبلی را ببندید.
2) کل پوشه Firouzeh_Kasse_Update_v0.6.0 را داخل این مسیر قرار دهید:
   D:\salon-cash-register
3) فایل APPLY_UPDATE_AND_START.bat را اجرا کنید.
4) نصب‌کننده قبل از جایگزینی فایل‌ها Backup می‌گیرد.
5) TypeScript و Build بررسی می‌شوند.
6) اگر Build شکست بخورد، نسخه قبلی خودکار برگردانده می‌شود.

اولین ورود
----------
در اولین اجرای این نسخه، فرم ساخت حساب مدیر نمایش داده می‌شود.
رمز عبور مدیر را در محل امن نگهداری کنید.

محدوده نسخه آزمایشی
-------------------
- رابط برنامه فقط فارسی است.
- نام خدمات و کتگوری‌ها مطابق لیست آلمانی سالن نمایش داده می‌شوند.
- خدمات CUT & STYLING ارسال‌شده در پروژه وارد شده‌اند.
- مدیر به داشبورد، فعالیت‌ها، خدمات و تنظیمات دسترسی دارد.
- کارمند فقط صفحه خدمات را می‌بیند.
- هر فعالیت با نام کاربر ثبت‌کننده ذخیره می‌شود.
- اطلاعات همچنان در IndexedDB همان مرورگر ذخیره می‌شوند.

مهم
----
این نسخه هنوز سرور مرکزی ندارد. حساب‌های کاربری و اطلاعات در همین مرورگر هستند.
برای استفاده هم‌زمان روی سیستم مدیر و لپ‌تاپ سالن، مرحله بعد Backend مرکزی و VPS است.

این نسخه قابلیت مخفی‌کردن، حذف اضطراری یا قطع دسترسی برای جلوگیری از بازرسی قانونی ندارد.
کنترل حساب کارمند فقط برای مدیریت عادی دسترسی و امنیت طراحی شده است.
