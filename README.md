# Firouzeh Hair & Beauty — v0.7.0-test

نسخه فارسی پنل داخلی سالن با مدیریت خدمات، کتگوری‌ها، کاربران،
ورودی و خروجی، تحلیل داده‌ها و طراحی واکنش‌گرا.

## امکانات این نسخه

- ۱۱ کتگوری و ۴۶ خدمت اولیه
- قیمت ثابت و «از قیمت پایه»
- ویرایش قیمت تک‌تک خدمات در لیست انتخاب‌شده
- محاسبه مالیات ۱۹٪ موجود در مبلغ
- مدیریت کتگوری خدمات و کتگوری هزینه‌ها
- ثبت ورودی و خروجی در دو تب جدا
- تحلیل براساس تاریخ، کتگوری و کاربر
- نقش مدیر و کارمند
- Modal مرکزی با Portal
- موبایل، تبلت و دسکتاپ
- بکاپ JSON و خروجی CSV قابل‌نمایش در Excel

> نسخه آزمایشی است و اطلاعات آن داخل مرورگر ذخیره می‌شود.
