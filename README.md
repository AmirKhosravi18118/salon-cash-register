# Firouzeh Salon Panel — v0.9.0-test

نسخه محلی تست برای مدیریت خدمات، فعالیت‌ها، شیفت، کاربران و تحلیل داده‌ها.

## اجرای محلی

```text
npm install
npm run typecheck
npm run build
npm run dev -- --host 127.0.0.1 --port 5173
```

یا فایل داخل پوشه آپدیت را اجرا کنید:

```text
APPLY_UPDATE_AND_START.bat
```

## اصلاحات اصلی نسخه 0.9

- اصلاح کامل چیدمان سبد در دسکتاپ و موبایل
- ورودی هوشمند مبالغ با پشتیبانی از نقطه، کاما و ارقام فارسی
- نمایش تمام عددها با ارقام انگلیسی
- فیلتر فعالیت‌ها براساس ماه و سال
- پرداخت مستقیم در صفحه خدمات و پرداخت از سبد
- مدیریت، تعلیق، حذف و تغییر رمز کارمند
- انتقال مستقیم دکمه تغییر ظاهر به تب Appearance
- تحلیل ورودی، خروجی، هزینه‌ها و شیفت‌ها
- موجودی دائمی صندوق پس از بستن شیفت
