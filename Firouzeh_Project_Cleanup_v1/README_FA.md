# پاک‌سازی امن پروژه Firouzeh

1. کل پوشه `Firouzeh_Project_Cleanup_v1` را داخل `D:\salon-cash-register` قرار دهید.
2. فایل `CLEAN_FIROUZEH_PROJECT.bat` را اجرا کنید.
3. با زدن `Y` ابتدا یک ZIP پشتیبان کنار پوشه پروژه ساخته می‌شود.
4. سپس فقط پوشه‌های آپدیت قدیمی، `dist`، `.update-backups` و `PROJECT_FILES.txt` حذف می‌شوند.
5. پوشه‌های `src`، `public`، `scripts`، `node_modules` و فایل‌های Docker حفظ می‌شوند.

6. در صورت فعال‌بودن ورود GitHub، پاک‌سازی خودکار Commit و Push می‌شود.
